## Relevant new or changed latest UX

1. **Reopen closed views (new local intake).** `view.reopenClosed`, default **Cmd/Ctrl+Shift+T**, tracks up to 20 closed views across scoped owners. Nonterminal panel surfaces can restore; Browser restores URL/viewport/profile and does not persist incognito history. Terminal sessions are excluded from closed-view recording. Deleted/unknown owners and unavailable workspaces are handled by restore planning. Close-all ordering records active view last so it restores first. Main shortcut forwards from focused embedded Browser through desktop IPC. Test Rig has no closedViewStore/reopenClosedView/command, so do not confuse reopening an existing inactive singleton tab with restoring a closed view. Sources: `.2752 apps/web/src/closedViewStore.ts:16–24,113–157`, `reopenClosedView.ts:25–64,108–170`, `components/ReopenClosedViewShortcut.tsx`, `rightPanelStore.ts`, `components/ChatView.tsx:5946–5962`, `packages/shared/src/keybindings.ts:134`, `packages/contracts/src/keybindings.ts:72`, desktop preview Manager/IPC delta. **Focused smoke:** close file/Review/browser views → Cmd+Shift+T; repeat with guest Browser focused; close-all → restore active first; terminal close must not resurrect dead process.

2. **Chosen diff scope stays put during a turn (fixed upstream regression).** `ChatView.logic.ts:186–194` now ignores auto-open when activeSurfaceKind is `diff` as well as `pull-request`: opening the already-open diff would reset user's chosen scope. Existing .2735 active-turn scope reset must not be reported as latest behavior. This does **not** add mutation refresh or make every terminal/external write observable. Test Rig uses an independent richer Review flow and does not contain this upstream auto-open decision helper, so do not mechanically import it. **Focused smoke:** choose an earlier turn/Unstaged in latest Diff, then start a turn that changes files; chosen scope must remain selected.

3. **Diff-header performance fix.** DiffPanel splits per-file collapse/suffix controls into small stable components/callbacks and AnnotatableCodeView caches rendered header slots rather than rerendering every header on each arriving patch. `components/DiffPanel.tsx:121–186,668–689,1152–1190`; companion `diffs/AnnotatableCodeView.tsx`, `useReviewFilePatches.ts`. This preserves UI affordances; measure/port only around Test Rig's richer Review, with no need to copy incompatible scopes.

4. **Published subagent model/effort/speed details.** `SubagentTooltipContent.tsx:53–105,137–153` shows effort and speed only when app-owned child model+provider-instance match the displayed agent metadata; it avoids borrowing unrelated child selections. `ThreadRelationshipsControl.tsx:385–390` and `V2LifecycleRow.tsx:548–556` supply origin/instance.
