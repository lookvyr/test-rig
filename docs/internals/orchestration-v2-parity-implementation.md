### Surface coverage and limits

Shared web/desktop entry points were covered through implementation and focused tests; live checks sampled the chat header, sidebar, Settings, command palette and shortcuts. Desktop-specific browser, menus and terminal behavior received native checks. Changed wire behavior has contracts and owning server/native implementations. Reverse states were exercised for snooze, archive, automation enablement and browser restoration.

The current pass used local loopback connections. Remote/tunnel/multi-environment acceptance was not performed. It did not live-inject lost provider requests or quota failures, monitor a real GitHub PR, simulate every filesystem error/large directory, exercise clipboard contents, or rerun every workflow across all three providers. Those relevant paths have focused tests/source review where described; the earlier audit contains the Codex/Claude comparison evidence. Video playback, browser cache isolation, and the out-of-order tool refresh race were verified through focused coverage rather than separate live fixtures. Two pre-existing shared file-preview suffix tests failed in an owner's extra run; their source/tests were unchanged and they are outside the final 44-file changed-scope run. No full-suite or release-certification claim is made.
