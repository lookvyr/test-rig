# Terminals

Open the bottom terminal panel with **Cmd+J** on macOS or **Ctrl+J** on Windows/Linux.
Its terminal tabs sit above the output. Select a tab to focus that terminal; **+**
opens another terminal in the current checkout. Session names, including setup
and project actions, appear on their tabs.

With a terminal focused, **Cmd+Option+Up/Down** on macOS or **Ctrl+Alt+Up/Down** on
Windows/Linux switches to the previous or next terminal tab. The selection wraps
at either end. Customize these as **Terminal: Previous Tab** and **Terminal: Next
Tab** in Settings → Keybindings.

The split buttons create side-by-side or stacked panes inside the current tab.
Split panes each have their own label and close button. A tab’s **×** immediately closes all its panes. The close-terminal shortcut closes only the focused pane.

**Hide terminal panel** and Cmd/Ctrl+J hide the panel without stopping its sessions.
Opening it again restores the tabs. Worktree setup and project actions keep using
their existing checkout and terminal sessions; switching tabs does not restart them.
